# Contributing

1. Fork the repo and create a branch: `git checkout -b feature/short-name`
2. Keep commits small with clear messages
3. Add or update tests in `tests/`
4. Never commit API keys; use environment variables
5. Open a pull request describing what and why

## Code style
- Python 3.11+, PEP 8, type hints where useful
- Every new tool must declare its permission level in `policy.yaml`
